១ សមីការភាព // សមីការឧស្ម័នបរិសុទ្ធ

PV = nRT = N·kBT = 23N·Kav
• គោលការណ៍ភាពដើម - ភាពស្រេច :
– ភាពដើម: P1V1 = nRT1 1
– ភាពស្រេច: P2V2 = nRT2 2

✳✳ ចំណាំ: បើបរិមាណឧស្ម័នភាយចេញក្នុងពេលបម្លែងនោះ n1 ≠ n2 ។

២ ទ្រឹស្ដីស៊ីនេទិចនៃឧស្ម័ន (ល្បឿន និង សម្ពាធលើផ្ទៃខាង)

• តម្លៃមធ្យមនៃល្បឿន:
vav = v1 + v2 + v3 + ... + vNN
• តម្លៃមធ្យមនៃការេល្បឿន:
(v2)av = v12 + v22 + v32 + ... + vN2N
• ល្បឿនឫសការេនៃមធ្យមការេ ឬ ល្បឿនប្រសិទ្ធ:
vrms = √v12 + v22 + v32 + ... + vN2N
• សម្ពាធលើផ្ទៃខាង:
P = FA

២.១ បម្រែបម្រួលបរិមាណចលនា & ចលនាម៉ូលេគុលក្នុងគូប

• បម្រែបម្រួលបរិមាណចលនា :
Δp = mΔv = m(vf − vi) | pi = mvi
pf = mvf
• អាំងពុលស្យុង : F × Δt = Δp
• ទង្គិចខ្នាត : ល្បឿនមុន និង ក្រោយទង្គិច v⃗f = −v⃗i (តម្លៃស្មើគ្នា ទិសដៅផ្ទុយគ្នា)
• ទង្គិចស្ទក់ : ល្បឿនក្រោយទង្គិច vf = 0
• សមីការចលនាត្រង់ស្មើ : x = vx × Δt
គំនូសបំព្រួញ៖ ចលនាម៉ូលេគុលឧស្ម័នក្នុងគូបប្រវែង L

> បើម៉ូលេគុលចេញពី A ដល់ B នោះវាចរបានចម្ងាយ x = L ។

> បើម៉ូលេគុលចេញពី A ទៅ B ហើយមកដល់ A វិញ នោះវាចរបានចម្ងាយ x = 2L ។

២.២ សម្ពាធ និង ថាមពលស៊ីនេទិចនៃឧស្ម័ន

• សម្ពាធក្នុងទ្រឹស្ដីស៊ីនេទិចនៃឧស្ម័ន :
P = 23NV × 12m0(v2)av = 23NV × Kav
P = 13mV × (v2)av = 13ρ × (v2)av
• ថាមពលស៊ីនេទិចមធ្យម ឬ ថាមពលស៊ីនេទិចនៃឧស្ម័ន ១ម៉ូលេគុល :
Kav = 12m0(v2)av = 12m0vrms2 = 32kBT
• ថាមពលស៊ីនេទិចសរុប :
K = N·Kav = 32N·kBT = 32nRT
• ល្បឿនប្រសិទ្ធនៃម៉ូលេគុលនីមួយៗ :
vrms = √(v2)av = √3kBTm0 = √3RTM

R = NA · kB
• ដង់ស៊ីតេម៉ាស // ម៉ាសមាឌ:

N = mm0 = n · NA
• ម៉ាសម៉ូល :

១ កម្មន្តនៃប្រព័ន្ធឧស្ម័ន (Work in Thermodynamic Processes)

• កម្មន្តនៃសម្ពាធថេរ (លំនាំអ៊ីសូបារ - Isobaric Process):
P = ថេរ
W = FΔx = PΔV = P(V2 − V1)
> កម្លាំងច្រានពីស្តុង : F = PA
> បម្លាស់ទីពីស្តុងពី x1 ទៅ x2 : Δx = x2 − x1
> មាឌទីតាំងដើម : V1 = Ax1
> មាឌទីតាំងស្រេច : V2 = Ax2
> ផ្ទៃមុខកាត់ស៊ីឡាំង : A = πr2 = πD24
> កាំមុខកាត់ស៊ីឡាំង : r = D2
ស៊ីឡាំង និង ពីស្តុងផ្លាស់ទីពី x₁ ទៅ x₂
ក្រាប P-V នៃលំនាំអ៊ីសូបារ (សម្ពាធថេរ)
• កម្មន្តនៃសម្ពាធប្រែប្រួលស្មើ :
W = P1ΔV + 12ΔP·ΔV = P1 + P22·ΔV

> បម្រែបម្រួលមាឌ : ΔV = V2 − V1

> បម្រែបម្រួលសម្ពាធ : ΔP = P2 − P1

• កម្មន្តនៃសីតុណ្ហភាពថេរ (លំនាំអ៊ីសូទែម):
T = ថេរ
W = nRT lnV2V1 = nRT lnP1P2
> តាមសមីការឧស្ម័នបរិសុទ្ធ:
ភាពដើម: P1V1 = nRT
ភាពស្រេច: P2V2 = nRT ⇔ V2V1 = P1P2
• កម្មន្តនៃមាឌថេរ (លំនាំអ៊ីសូករ - Isochoric):

កាលណាមាឌឧស្ម័នថេរ (V = ថេរ ⇒ ΔV = 0) នោះប្រព័ន្ធមិនបំពេញកម្មន្តទេ៖

W = 0
ក្រាប V-T (មាឌថេរ - លំនាំអ៊ីសូករ)

២ ច្បាប់ទី១ ទែម៉ូឌីណាមិច និង កតិកាសញ្ញា

បើប្រព័ន្ធប្រែប្រួលកម្ដៅ ហើយបំពេញ ឬរងកម្មន្ត នោះថាមពលក្នុងវាក៏ប្រែប្រួលដែរ៖

ΔU = Q − W  ⇔  Q = ΔU + W
> បើប្រព័ន្ធធ្វើកម្មន្ត ⇒ W > 0
> បើប្រព័ន្ធរងកម្មន្ត ⇒ W < 0
> បើប្រព័ន្ធស្រូបកម្ដៅ ⇒ Q > 0
> បើប្រព័ន្ធបញ្ចេញកម្ដៅ ⇒ Q < 0
> បើប្រព័ន្ធកើនថាមពលក្នុង ⇒ ΔU > 0
> បើប្រព័ន្ធថយថាមពលក្នុង ⇒ ΔU < 0

៣ ថាមពលក្នុងនៃប្រព័ន្ធឧស្ម័ន

• ថាមពលក្នុងដើមឧស្ម័ន :
U1 = 32nRT1
• ថាមពលក្នុងស្រេចឧស្ម័ន :
U2 = 32nRT2
• បម្រែបម្រួលថាមពលក្នុង :
ΔU = U2 − U1 = 32nRΔT

៤ គោលការណ៍សមមូល // បម្លែងស៊ិច

បម្លែងមួយស៊ិច នោះថាមពលក្នុងឧស្ម័នមិនប្រែប្រួល ΔU = 0 តែ Q = ΔU + W ⇒ Q = W

៥ គោលការណ៍ភាពដើម - ភាពស្រេច

កាលណាប្រព័ន្ធមួយទទួលបម្លែងពីភាពដើមទៅភាពស្រេចដោយប្ដូរតែកម្ដៅ និងកម្មន្តជាមួយមជ្ឈដ្ឋានក្រៅ នោះតម្លៃពិជគណិត ΔU អាស្រ័យតែភាពដើម និងភាពស្រេចប៉ុណ្ណោះ៖

ΔU1 = ΔU2 = ΔU3
Q1 − W1 = Q2 − W2 = Q3 − W3
